# PERT 專案流程

把 Blair Singer《PERT》手冊的紙本里程碑卡片，數位化成可以快速輸入的工具。

## 它做什麼

- **倒推建立里程碑**：從最終目標往回問「在那之前必須先完成什麼？」，打字按 Enter 就串成一條流程線
- **批次貼上**：一行一個里程碑，可直接從紙本或 Excel 貼進來
- **自動算日期**：你只填「時間（幾天）」和「前置事件」，系統算出每件事的最早可開始日、最晚須完成日、彈性時間（鬆弛）
- **自動標要徑**：彈性最小的那一串用紅底標示 —— 那條線一延誤，整個專案就延誤
- **四種檢視**：表格（快速輸入）／卡片（還原紙本六欄位，可列印貼牆）／流程圖（自動排版的 PERT 網絡圖）／匯出 CSV·JSON·PDF
- **兩個內建範本**：鳥舍（教學用，4 個里程碑）、從自由工作者到可擴展的事業（手冊完整範例，41 個里程碑）

## 計算規則

依手冊的定義實作，並以手冊第 6-8 頁印出的實際數字驗證：

| 名詞 | 定義 |
|---|---|
| 最早日期 | 專案起始日 + 所有前置路徑中最長的那條工期總和 |
| 最晚日期 | 從截止日往回推，此事件最晚必須完成的日期 |
| 彈性時間 | 最晚日期 − (最早日期 + 本事件工期) |
| 要徑 | 彈性時間最小的那一串事件 |

沒設截止日時，要徑的彈性為 0。截止日比最快完成時間早時，會跳「排不下」警告並算出差幾天。

## 目錄

```
public/          網站本體（純 HTML/CSS/JS，無需編譯、無相依套件）
  pert.js        計算引擎（純函式）
  templates.js   兩個內建範本
  store.js       資料層 — 將來接資料庫只改這一支
  app.js         介面
test_engine.js   引擎測試（40 項，對照手冊印出的真實日期）
test_ui.js       介面測試（61 項，jsdom 掛整個頁面按真的按鈕）
```

## 測試

```bash
node test_engine.js      # 40 項
node test_ui.js          # 61 項（需要 jsdom）
```

## 現階段限制

資料存在**使用者自己的瀏覽器**（localStorage）。換一台電腦或換瀏覽器會看到空白，兩個人也看不到彼此的資料。

多人帳號與「公開給同事讀取」會在併入 WINEX 戰情室時一起做 —— 帳號與權限由戰情室提供，`store.js` 換成資料庫驅動即可，介面不用改。
